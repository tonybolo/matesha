# Матеша

Веб-приложение для изучения школьной математики: **объяснение → проверка понимания → тренировка**.
Формулы набраны в KaTeX, как в учебнике; у каждой темы своя интерактивная визуализация.
Работает на телефоне и компьютере, устанавливается на домашний экран (PWA). Потом на этой же основе
можно сделать нативные приложения для iOS и Android.

Сейчас в приложении три раздела и режим **«Контрольная»**:

**Алгебра** (учебник Макарычева, 8 класс):

0. Сложение и вычитание рациональных чисел — повторение: числа со знаками, десятичные и обыкновенные дроби.
1. Рациональные дроби и их свойства (ОДЗ, основное свойство, сокращение).
2. Сложение и вычитание рациональных дробей (общий знаменатель).
3. Произведение и частное дробей (умножение, деление, степень дроби, обратная пропорциональность, график гиперболы) — КР № 2.
4. Квадратный корень. Сравнение корней (иррациональные числа, сравнение, когда корень существует, график y = √x) — КР № 3.
5. Упрощение выражений с корнями (вынести множитель, дроби, формулы сокращённого умножения, корень в знаменателе) — КР № 4.
6. Квадратные уравнения (неполные, дискриминант, формула корней, задачи, Виета) — КР № 5.

**Геометрия** (Атанасян, 8 класс, глава «Четырёхугольники»):

1. Определения четырёхугольников (параллелограмм, прямоугольник, ромб, квадрат, трапеция, сумма углов).
2. Задачи по теме «Параллелограмм, трапеция» (углы, стороны, диагонали, биссектриса, признаки, средняя линия, площади).

**Вероятность и статистика**:

1. Математическое ожидание. Дисперсия (среднее и разброс, таблица распределения, E(X), D(X), σ).

В каждой теме: урок «на пальцах» с интерактивной картинкой, проверка понимания и тренажёр. Тренажёр состоит из
**типов заданий**; задания каждого типа создаёт генератор (по 24 штуки, три уровня: «как в учебнике», «посложнее», «с подвохом»).
Группы со звёздочкой ⭐ — олимпиадные задачи (в процент прохождения темы не входят).

**План к контрольной** на главной: три шага (сравнить, упростить, решить) — урок, потом минимум по пять задач каждого типа, и кнопка ведёт
сразу на следующий тип.

**Контрольная**: «как в классной работе» (сравнить, упростить, решить) или КР № 2, 3, 4, 5 в формате учебника-задачника
(части А, В, С), с таймером, новым вариантом каждый раз и разбором ошибок со ссылкой на нужный урок. Результаты и
ошибки по навыкам копятся в прогрессе: на главной появляется блок «Что стоит повторить».

## Как запустить

```bash
cd web
npm install
npm run dev        # http://localhost:5173
npm test           # тесты: проверка ответов, контент, прогресс
npm run build      # сборка в web/dist
```

Прогресс (имя, очки, серия дней, решённые задачи) хранится в браузере (`localStorage`).

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` сам прогоняет проверки, собирает сайт и публикует его.
Один раз нужно включить Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес будет `https://<пользователь>.github.io/matesha/`. Дальше публикация идёт после каждого push.
Если первый запуск workflow упал на шаге deploy (ошибка 404 «Ensure GitHub Pages has been enabled»), включи Pages и перезапусти его: **Actions → последний запуск → Re-run all jobs**.

## Где что лежит

```
content/algebra8/*.yaml          темы алгебры: уроки, проверочные вопросы (+ вручную записанные задачи)
content/geometry8/*.yaml         темы геометрии
content/stats8/*.yaml            темы вероятности и статистики
content/*8/generated/            задания, созданные генераторами (JSON)
content/skills/*.yaml            навыки и уроки, где они объясняются (основа поиска пробелов)
content/cheatsheet/*.yaml        шпаргалка с формулами (по разделам)
docs/ADDING_TOPICS.md            как добавить тему: файлы, формат, генератор, картинки, проверки
tools/generators/                генераторы заданий (Python + SymPy) и их независимая проверка
tools/verify_answers.py          проверка вручную записанных задач через SymPy
web/src/lib/                     проверка ответов (mathjs), сборка контрольной
web/src/components/              экраны: главная, урок, проверка, тренажёр, контрольная
web/src/viz/                     интерактивные картинки уроков (*Viz.tsx) и рисунки к заданиям (fig/*Fig.tsx)
web/src/store/                   прогресс, очки, слабые места
```

Раздел темы задаётся полем `subject` в YAML (`algebra`, `geometry`, `stats`); новые файлы подхватываются сами, общий код менять не нужно.

## Генераторы заданий

```bash
pip install sympy pyyaml
python3 tools/generators/run.py              # пересоздаёт content/*8/generated/*.json (или одну тему: run.py <id темы>)
python3 tools/generators/verify_generated.py # пересчитывает каждый ответ независимо через SymPy
```

Каждая группа — функция `g_имя(rng, level)` в `tools/generators/topicN.py` (алгебра 8, олимпиадные — в `olympN.py`) или в `tools/generators/t_<имя>.py` (новые темы любого раздела, с собственной независимой проверкой `verify`); она возвращает
условие, ответ, подсказку, решение по шагам и список навыков. Генерация воспроизводимая (зерно зависит от темы и группы).
Проверка в `verify_generated.py` не доверяет генератору: ответ считается заново из условия.

## Как добавить тему или задачи

Подробная инструкция (файлы, формат урока, генератор, картинки, проверки): [`docs/ADDING_TOPICS.md`](docs/ADDING_TOPICS.md).

Тема — один YAML-файл в `content/<раздел>8/`. Формулы пишутся в `$…$` (LaTeX), жирный текст в `**…**`.
Вручную записанная задача (в основном для алгебры):

```yaml
- id: t1-99
  level: 1                # 1 — как в учебнике, 2 — посложнее, 3 — с подвохом
  source: упр. 12 (а)     # откуда задача
  prompt: 'Сократите дробь {expr}.'   # {expr} заменяется формулой из expr
  expr: '(x^2-9)/(x^2+3x)'            # запись для компьютера: x^2, дробь через /
  answerKind: expr        # expr — выражение, roots — набор чисел через «;»
  answer: '(x-3)/x'
  reduce: true            # ответ должен быть одной несократимой дробью
  verify: {op: reduce}    # как SymPy проверит ответ (reduce | simplify | value | odz | custom)
  hint: 'Разложи числитель и знаменатель на множители.'
  solution:
    - '$\frac{(x-3)(x+3)}{x(x+3)}$'
    - 'Сокращаем на $(x+3)$: $\frac{x-3}{x}$'
```

После правок:

```bash
pip install sympy pyyaml
python3 tools/verify_answers.py      # ответы совпадают с вычислением SymPy
cd web && npm test                   # все формулы собираются в KaTeX, эталонные ответы принимаются
```
